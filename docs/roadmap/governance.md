# Governance

HumaWare starts as a maintainer-led project and should evolve toward working groups as the ecosystem grows.

## Expected Working Groups

- core runtime
- safety and validation
- hardware adapters
- simulation and benchmarking
- AI policy runtime
- fleet and operations

## Maintainer Expectations

Maintainers should prioritize:

- stable public contracts
- reproducibility
- safety review
- clear release notes
- migration paths
- evidence for real-robot claims
