# Benchmarks

HumaWare benchmarks measure integration quality, not just motion performance.

Initial benchmark areas:

- bringup success rate
- time to active
- navigation success rate
- fall or near-fall count
- MRM trigger latency
- teleop latency
- DDS packet loss behavior
- CPU, GPU, and memory use
- battery and thermal behavior
- recovery success rate
- rosbag replay reproducibility
