# Roadmap

## Phase 0: Foundation

- README, manifesto, architecture, roadmap, safety policy
- ROS 2 package skeleton
- Docker and devcontainer
- CI
- first custom messages
- AGENTS.md project rules

## Phase 1: Simulation MVP

- lifecycle bringup
- mock robot
- teleop
- Nav2 bridge
- basic safety manager
- rosbag record and replay
- Gazebo or MuJoCo demo
- "run in 10 minutes" documentation

## Phase 2: First Real Robot

- first verified real humanoid adapter
- real teleop
- stand, walk, stop interface
- Nav2 goal demo
- MRM on timeout or network loss
- diagnostics dashboard
- benchmark v0.1
- video, logs, robot model, firmware, and git SHA

## Phase 3: Developer Ecosystem

- hardware adapter template
- second robot support
- MoveIt bridge
- Open-RMF adapter prototype
- LeRobot data collection bridge
- OpenVLA experimental bridge
- Behavior Tree plugin examples
- monthly release cadence

## Phase 4: Real-World Deployment

- multi-robot namespace conventions
- remote operator console
- incident replay tooling
- policy safety gate
- fleet coordination demo
- lab or warehouse scenario benchmark
- stable core API

## Phase 5: Foundation-Grade OSS

- independent governance
- CODEOWNERS
- working groups
- release train
- reference hardware program
- certification-oriented safety documentation
- commercial adopter program
